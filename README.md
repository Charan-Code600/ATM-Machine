

# 🏦 ATM Machine

A simple ATM simulator built with Python.

## Features
- 🔐 PIN Protection (3 attempts)
- 🔒 Account Lock after 3 wrong PINs
- 💰 Balance Check
- 💸 Withdraw Money
- 💵 Deposit Money
- 📋 Transaction History
- ⚠️ Minimum Balance Rule (₹1,000)

## How to Run
```bash
python atm.py
```

## Default PIN
1234

## Technologies Used
- Python
- Lists
- Loops
- Conditionals
