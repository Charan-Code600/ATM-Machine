



# 🏦 ATM Machine

A simple ATM simulator built with Python.

## Features

- 🔐 PIN Protection (3 attempts)
- 🔒 Account Lock after 3 wrong PINs
- 💰 Balance Check
- 💸 Withdraw Money
- 💵 Deposit Money
- 📋 Transaction History (saved permanently to file)
- ⚠️ Minimum Balance Rule (₹1,000)
- 💾 Data Persistence — balance and history are saved to files, so your data stays even after closing the program

## How to Run

\`\`\`
python atm.py
\`\`\`
